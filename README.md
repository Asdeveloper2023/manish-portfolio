## Run Locally

Clone the repository:

```bash
git clone https://github.com/Asdeveloper2023/manish-portfolio.git
```

Navigate into the project:

```bash
cd manish-portfolio
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Open http://localhost:3000 in your browser.
